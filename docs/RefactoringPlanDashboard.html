코드와 실제 Host 연결을 기준으로 문서를 다시 작성했다. 빌드·Editor/Player 실행·GPU 품질·성능·GUI 수용은 이번 개정에서 수행하지 않았다. 과거 완료율·공수 합계는 현재 제품 지원율이 아니므로 이 지도에서 재계산하지 않는다.

실행 경로의 출발점

Host와 프레임

Editor/Player → EngineBootstrap → RuntimeFrame → EndOfFrame → sealed live packet. Host의 편집·표시·오디오 소유권은 공통 simulation과 구분한다.

기술 안내

렌더링과 재질

METEOR 단계, versioned RenderGraph, exact material generation과 cooked stage 계약을 함께 읽는다. 실험·회귀 helper를 제품 경로로 오해하지 않는다.

실제 파이프라인

저작과 자산

편집 draft, 외부 변경 충돌, 비동기 준비, 불변 세대와 owner 경계 게시를 분리한다. source-free runtime은 원본 decode로 실패를 복구하지 않는다.

텍스처 흐름

빌드와 배포

엔진 배포와 프로젝트 pin을 확인하고 candidate → Verify → publish를 따른다. skip-verify는 current package를 바꾸지 않는다.

패키징 계약

증거의 범위

다른 open PR의 기능은 기준 master에 포함하지 않는다. 날짜별 측정 JSON·이미지는 원래 bytes를 보존한 역사 자료이며 현재 수용 결과가 아니다. 각 문서는 구현 근거와 지원/검증 한계를 별도로 둔다. 이전 계획의 원문은 기준 commit의 역사 대시보드에서 확인할 수 있다. 그 원문의 체크박스·공수·검증 주장은 현행 판정으로 승계하지 않는다.
