Transform 갱신 파이프라인

실행 투영·dirty 게시·즉시 읽기·렌더 제출의 현재 연결을 보여 주는 정적 안내다.

정본과 파생 상태

local TRS는 Transform 저작 값, hierarchy는 Scene HierarchyStore, local/world 행렬과 world TRS cache는 Scene TransformStore가 보관한다. EntityHandle의 slot/generation은 compiled graph 위치와 다르다. Scene/Entity/Component 메모리 수명은 공유 GCCE domain과 trace 관계로 관리한다.

쓰기 → dirty publication

setter/local matrix write → PublishLocalWrite(reason) → spatial dirty queue/epoch 및 관련 proxy·physics invalidation 순으로 연결된다. world 결과의 bulk writer는 ApplyWorldWriteBatch를 사용한다. local dirty와 worldChanged는 다른 값이며 즉시 resolve 뒤에도 아직 자식에게 알리지 않은 world 변경을 보존한다.

topology → 실행 투영

생성/파괴/reparent → topology version → EnsureExecutionGraphsCompiled/CompileExecutionGraphs 순이다. canonical Reparent는 stale/cross-scene/self/cycle을 거부하며 compiler도 손상 hierarchy를 검사한다. dense order는 canonical hierarchy의 복제 정본이 아니라 재생성 가능한 실행 데이터다.

동기화와 즉시 pull

AllUpdateWorldMatrix/SyncDerivedState가 spatial과 UI domain을 구분한다. sparse resolver는 dirty roots와 compiled projection을 사용하고 epoch로 순회 중 새 write를 보존한다. EnsureResolved는 world getter의 ancestor chain만 앞당기며 그 뒤 전체 propagation과 일관돼야 한다.

UI는 screen extent·Canvas scale·RectTransform dirty를 확인한다. spatial이 정적이라는 이유로 UI를 건너뛰지 않는다. RectTransform 자체는 child recursion을 하지 않는다.

animation·physics → render

animation worker 두 group은 join 후 owner가 pose/socket을 Scene에 게시한다. Physics는 고정 tick 결과를 world batch로 반영하며 render interpolation은 별도 읽기다. Scene::LateUpdate의 UpdateRenderData가 proxy dirty를 소비한다. frame이 봉인된 뒤 renderer는 live Scene traversal 대신 packet/delta를 소비한다.

범위와 확인 방법

sparse/full movement, topology churn, 즉시 getter, UI resize, 관측 bone, physics writer, proxy payload 변경을 별도 검사한다. 이 문서는 source 흐름을 정리했으며 벤치마크나 시각 비교를 실행하지 않았다. 상세 API와 선택적 확장은 Transform 계약이 정본이다.

이전 페이지에 포함됐던 다이어그램 렌더러 번들은 현재 동작의 측정 원자료가 아니므로 정적 설명으로 대체했다. 별도 측정 JSON·이미지 파일은 변경하지 않았다.
