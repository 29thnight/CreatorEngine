현재 제품 배선

BuildPipelineDesc의 METEOR.Scene.Shadow는 Geometry 출력을 읽는다. EnhancedShadowPass는 cascade 계산·target 선언/clear·설정의 역할이고 실제 SceneHost ShadowStage가 cascade별 visible list와 indirect 명령을 생산·소비한다. 삭제된 표준 material shadow 또는 과거 LX indexed fallback을 현재 제품 경로로 다시 소개하지 않는다.

GeometryStage의 posed object-space stream과 인스턴스 world transform, material coverage를 사용한다. GpuGeometryVisibility의 cascade 입력은 light-space 행렬이며 카메라 HZB 또는 카메라 visible list로 caster를 제거하지 않는다. 각 C0/C1/C2가 해당 깊이 slice를 수정하며 command input·visible IDs의 graph read도 명시한다.

보수적 선택과 LOD

현재 spatial replacement LOD hierarchy는 카메라와 cascade별로 다른 cut을 선택할 수 있다. 옛 LOD0-only shadow 설명은 현행 전체 계약이 아니다. parent/child의 원자적 대체·source primitive mapping·posed vertex owner를 유지해야 한다. masked·sidedness·음수/비균일 scale·skin·near plane을 단순 bind-pose cone으로 탈락시키지 않는다.

ShadowMath의 receiver overlap과 광원 방향 backOff는 카메라 밖 먼 caster가 cascade near plane에 잘리는 것을 막기 위한 실제 입력이다. 계산 실패·비유한 경계까지 안전하다는 일반 보증은 아니므로 보수 fallback/거부를 사례별로 확인한다. persistent shadow-depth cache의 재사용은 현재 live 기능이 아니다.

남은 수용

같은 sealed 입력에서 독립 CPU clip/LOD oracle과 GPU 인자·목록을 대조한다. 3장 depth는 같은 행렬·coverage·pose로 비교하고 실제 그림자를 만드는 필수 메시렛 누락 변이가 oracle을 실패시켜야 한다. 텍스처 공간 alpha, cascade boundary, far/off-camera caster, 직교/원근·움직이는 pose와 여러 view를 포함한다.

성능은 cull compute·list/argument upload·mesh dispatch·shadow depth·CPU 준비·VRAM의 전체 비용이다. CPU audit의 거부율은 GPU readback 생존 수나 절감 ms가 아니다. timestamp 누락·unsupported 구간은 0ms로 계산하지 않는다. 반복 성능 이득과 제품 기본 활성화는 선택 정확성 통과와 별도 판정한다.

이 문서는 과거 선택 DX12 fixture의 수치·24회 측정·ABI 20 결과를 현행 커밋의 실행으로 재인용하지 않는다. 구현과 entry-point는 확인했지만 이번 빌드/GPU 실행은 없었다. Vulkan 교차 수용은 BackendParityPlan이 소유한다.
