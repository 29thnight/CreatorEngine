2026-10-20 정리 · master 27de3f5a02aadde7456aab680db3184c36ee735e · 잔여 구현·수용 계획

판정 기준은 위 master의 커밋된 소스다. 작업 중인 로컬 코드 변경은 포함하지 않는다. 완료된 구현 단계·날짜별 실행 일지는 제거했다. 대시보드는 SRP 저작 전환 취소에 해당하는 항목만 제거하고, 나머지 상태·공수·링크를 보존한다.

전체 문서 대조·충돌 판정 · 정리 전 원문

§01

남은 작업과 완료 판정

  • W2-V/W2-B·W7/W8의 남은 편집 표면/동작과 멀티뷰·복구·제품 UI 수용을 닫는다. 완료된 shell chrome·메뉴/창 선언 M0M4와 W0W6 기반은 제거한다.
  • W9의 설정 저장/프로필/품질/Player 계약은 EditorRenderingSurfacesPlan으로 단일화한다. 이 W9는 완료된 PBR-W9와 다른 작업이다.

§02

적용할 구조와 경계

Editor window/commands → common editing transaction → scene component → dirty publication

위 경로는 소스에서 확인한 구현 기반이다. 아래 요구의 수용 결과를 뜻하지 않는다. 구현을 다시 만드는 항목과 제품 검증을 혼합하지 않는다.

§03

미래 자체 편집기 UI와의 경계

2026-10-28 등록한 엔진 공통 UI 기반과 자체 편집기 UI 전환 계획은 현재 리팩토링 이후의 FUI 미래 항목이다. 본 계획은 현재 ImGui 셸·도킹·ViewportHost·workspace와 기존 W 항목의 제품 동작을 계속 소유한다. FUI는 새 위젯 및 도킹 구현으로의 전환과 동등성 수용을 소유한다. 기존 명령·편집 트랜잭션·stable ID·저장/복구 의미를 승계하고, FUI가 통과하기 전에 현재 셸을 철거하거나 W 항목을 완료로 바꾸지 않는다.

§06

검증 경계

이번 정리는 master 소스·문서 전체의 소유권/충돌/링크/HTML 검증이다. 엔진 빌드·GPU 픽셀·SDK/장치·성능·실제 GUI 수용을 새로 실행한 결과가 아니다. 과거 통과는 해당 소스/바이너리 신원에만 유효하다. 남은 제품 수용은 위 요구를 실제 산출물로 닫아야 한다.
