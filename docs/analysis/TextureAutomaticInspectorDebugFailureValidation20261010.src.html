잔여와 진행률

파일 잠금 자동 저장 오류가 Texture sidecar must have a valid canonical UUIDv4 identity로 표시된다. 실제 파일 신원은 정상이고 읽기가 잠금으로 실패했으므로 원인 구분 진단은 잔여다. 삭제, 저장 대기 중 손상 외부 bytes 충돌, 최종 비교 이후 동시 쓰기, 반복/장시간, 다중 창/배율은 미실행이다. Debug 종료 충돌 재검증과 다른 소비자/GPU/품질도 확대 수용하지 않는다.

이번 한정 Debug 입력·실패 재읽기·오류 해제 수용을 12-0-D 0.25일로 분리한다. T0 잔여는 0.25일, 활성 총20일은 유지한다. 완료13.25/20 = 66.25%, 대시보드 반올림 66%. 계획 가중치이며 실제 투입 시간이나 전체 T0 완료를 뜻하지 않는다.
