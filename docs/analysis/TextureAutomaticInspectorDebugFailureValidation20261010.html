§01

재현 및 로컬 증거

격리 fixture 준비와 Editor 실행을 저장소의 start-texture-auto-ui.ps1에 보존했다. 먼저 소비자 회귀로 만든 Build/TextureReimportScene/result.json의 project를 FixtureProject로 전달하고 conflict 또는 manual 모드로 실행한다. 준비 명령은 씬·브라우저만 열며 값 편집과 Reload/Retry는 실제 UI 입력이다. 외부 충돌 probe와 파일 잠금·손상은 제어된 실패 주입이다. manual 실행의 첫 잠금은 선택 전에 걸려 Inspector를 읽지 못했다. 잠금을 해제해 선택한 뒤 다시 잠그고 편집한 실행만 자동 저장 실패 수용에 사용했다.

  • 집계 receipt
  • Debug 소비자 회귀
  • 외부 충돌 receipt
  • 잠긴 파일 Reload
  • 손상 후 편집 값 2
  • 손상 파일 Reload
  • Retry 정상 상태
  • Retry 오류 해제
  • 자동 저장 잠금 실패
  • Reload 복구
  • 새 편집 복구
  • 정상 종료 로그: Build/TAUI-Debug-{conflict-6d2c7780,manual-6c1e823c}/editor.out

Build 증거는 로컬 산출물이며 Git에 포함하지 않는다. 과거 실행의 Build fixture가 정리되어 현재 실행은 새 fixture로 재검증했다. 이전 기록을 이번 실행 결과로 소급 대체하지 않는다.

§02

잔여와 진행률

파일 잠금 자동 저장 오류가 Texture sidecar must have a valid canonical UUIDv4 identity로 표시된다. 실제 파일 신원은 정상이고 읽기가 잠금으로 실패했으므로 원인 구분 진단은 잔여다. 삭제, 저장 대기 중 손상 외부 bytes 충돌, 최종 비교 이후 동시 쓰기, 반복/장시간, 다중 창/배율은 미실행이다. Debug 종료 충돌 재검증과 다른 소비자/GPU/품질도 확대 수용하지 않는다.

이번 한정 Debug 입력·실패 재읽기·오류 해제 수용을 12-0-D 0.25일로 분리한다. T0 잔여는 0.25일, 활성 총20일은 유지한다. 완료13.25/20 = 66.25%, 대시보드 반올림 66%. 계획 가중치이며 실제 투입 시간이나 전체 T0 완료를 뜻하지 않는다.
