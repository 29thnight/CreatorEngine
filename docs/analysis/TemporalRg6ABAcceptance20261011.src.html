이전 근거의 유효 범위

각 경로/구성 첫 프로세스 graph capture 100회, 두 번째 2회이며 일반 프레임 비용 표본은 프로세스마다 100개다. 정상 종료, GPU validation enabled/problems 0/dropped 0, 실제 scene Ready, 서로 다른 CPU 측정/GPU 프레임, 원래 명령 응답과 저장 행의 일치를 요구한다. 전체 manifest의 입력/그래프 identity를 감사하고 선택 대표의 프로세스 내/간·A/B·제품 D/R 픽셀을 비교한다. 408캡처 전체 이미지의 모든 쌍을 비교했다는 의미는 아니다.

현재 그래프 차이

GpuGeometryOcclusion::LevelCount처럼 각 차원을 올림 절반으로 줄여 1×1까지 계산한다. 332×182에서는 9 mip이다. LX-only authored geometry는 traditional occluder depth가 없어 제품 ExplicitVersioned 경로에서 LX.Scene.OccluderDepth prepass/resource가 추가된다. GizmoIcon.Texture 명시 read 2개와 Cull→CullOcclusion 대체를 별도로 요구한다.

EnhancedPbrCapture::DeclareStage는 index/version/kind/epoch가 같은 versioned image만 readback을 공유한다. 비활성 Forward+/Sprite/SSS/SSR/LX.Scene.Volume/Temporal.Upscale의 중복 PBR.Stage 패스는 제거되지만 이름별 diagnostic image와 모든 단계의 픽셀 비교는 유지한다. 수용 도구는 manifest에 증명된 sharedReadback에 대응하는 정확한 패스 차이만 허용한다. 예상 밖 패스/리소스 또는 pixel threshold를 느슨하게 허용하지 않는다.
