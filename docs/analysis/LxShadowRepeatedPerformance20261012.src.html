이전 근거의 유효 범위

기존 세부 계약은 위 현행 구현과 모순되지 않는 범위에서 유지한다. 과거 수치·실행 통과·해시·장치 조건은 당시 기록이다. 로컬 산출물이 사라진 항목은 링크 대신 경로와 미보존 상태를 표시하며, 현재 master의 재실행 통과로 승격하지 않는다.

세부 계약·원래 분석과 당시 측정 기록

기존 목록 7번의 선택한 합성 범위 측정을 완료했다. GPU 계측 용량을 1024에서 4096 패스/프레임으로 늘려 MatGrid 8×8의 1710개 구간을 누락 없이 수집했다. 현재 Release 바이너리로 3개 장면, 경로별 4회씩 총 24개 정상 기록을 확보했다. 측정 산출물은 통과했지만 성능 이득은 수용하지 않는다. 세 장면 모두 그림자 평균합 비교의 독립 반복 CV 기준을 통과하지 못했다.

변경과 방법

  • EnhancedSceneRendererLiveDX12Adapter.cpp의 그래픽/compute 초기화 용량을 공통 상수 4096으로 통일했다. 3프레임에서 24,576개 timestamp query, 192 KiB readback을 예약한다. 메타데이터 메모리는 별도이며, 이 상한을 넘으면 여전히 계측 실패다. 무제한 용량이나 동적 증가를 구현하지 않았다.
  • measure-lx-shadow-meshlets.ps1은 C0/C1/C2가 모두 계측됐는지 검사하고 호출당 시간, CPU 준비·기록 비용, 시작/종료 카운터, 소스·바이너리 해시와 정상 종료를 기록한다. 상속된 Debug query 제한은 제거한다.
  • measure-lx-shadow-repeat.ps1은 indexed→meshlets→meshlets→indexed를 두 번 실행한다. 독립 프로세스·격리 프로젝트, 경로별 4개의 8초 녹화다. 측정 중 다른 빌드나 GPU 검증을 실행하지 않았다.
  • assess-lx-shadow-performance.py는 프로파일 SHA, 출처, 동일 모델·셰이더·배치·카메라 입력, 동일 바이너리와 해상도, 실뷰당 3개 캐스케이드 누락 없음, 정상 종료를 확인한다. 동일 캡처의 반복 제출은 의도적으로 거부했다.
  • 변동계수는 4개의 독립 녹화 평균에 대한 sample SD / mean이다. 두 경로 모두 CV ≤ 10%여야 안정성 기준 통과다. 표의 변화율은 (meshlet/indexed-1)*100이며 음수는 비용 감소다. 불안정한 평균의 방향을 확정 이득/손실로 수용하지 않는다.

제외한 실패와 보관

  1. MatGrid 16×16 탐색은 aggregate chunk/CPU/GPU payload 제한을 넘었다. 측정 전에 제외하고 로그와 review를 보존했다.
  2. 수정 전 1024 슬롯의 MatGrid 8×8은 overflow 카운터가 13,178→30,328로 증가해 거부했다. 해당 실패와 이전 바이너리의 Suzanne 8회 기록은 보존하되 새 평균에 섞지 않았다.
  3. 수정 후 MatGrid 마지막 indexed 캡처는 complete=false였다. 슬롯 초과/손실 카운터는 0이지만 녹화 종료 262.28 ms 시점에 GPU 제출 하나가 남아 stop drain deadline을 넘었다. 원본 .ceprof와 판정을 보존하고 제외했다. 원인을 검토한 뒤 동일 바이너리·동일 절차·동일 기준으로 한 번 재실행했고 complete=true, pending GPU=0으로 통과했다. 250 ms stop drain 경계 자체를 수정하거나 실패를 정상화하지 않았다.
  4. 추가 반복 도구에서 빈 배열 초기화가 null로 열거되어 dictionary merge 오류가 났다. 명시적 배열로 수정했다. 이미 통과한 두 정상 캡처를 검증해 목록을 복구했고 이전 manifest와 복구 기록을 보존했다. GPU 결과를 재작성하지 않았다.

모든 .ceprof, 로그, 원시 평균 표본, SHA, manifest와 판정을 보존했다. 매 GPU 실행 전 실제 여유 공간 30 GiB 이상을 확인했다. 이 측정은 원본 그림자 픽셀을 캡처하지 않았고 픽셀 동치 판정을 새로 부여하지 않는다. 이전 12개 합성 정확도 검증의 Debug/Release 원본 144개씩은 보존했다.
