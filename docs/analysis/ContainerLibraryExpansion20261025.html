§00

범위와 검증

일반 배열·문자열·해시맵을 비단순 타입/이동 전용 값/예외 복구/사용자 할당자로 확장했다. 문자열 키 맵·셋, 세대 핸들 slot map, sequence buffer, intrusive LRU, 문자열 atom, age buckets, inplace function, 안정 32/64비트 radix sort, fixed/monotonic/TLSF resource를 추가했다. STL 컨테이너/문자열/알고리즘은 검증 실행 파일에서만 사용한다. 배포 헤더는 언어·CRT 기능을 사용한다.

  • MSVC Release: 기존 큐를 포함한 CTest 7/7.
  • MSVC ASan, ClangCL Release, WSL Clang 18 Release, WSL ASan+UBSan: 일반/확장 정확성 각각 2/2.
  • 공개 헤더 17개 각각 독립 컴파일: MSVC, ClangCL, WSL Clang.
  • 무작위 문자열 50,000회, 문자열 키 맵 120,000회, slot map 60,000회, sequence 100,000회, LRU 100,000회, age buckets 50,000회, TLSF 100,000회. 할당 실패, 예외, 이동 전용 소유권, stale/cross-owner 핸들, 정렬 안정성도 검사한다.

§01

측정 방법과 한계

MSVC Release / iterator debug 0, 3개 프로세스, 각 15개 표본, 3회 워밍업, A/B 순서 교대, 짧은 작업은 약 2ms 이상 배치한다. 테스트·빌드와 벤치마크는 동시에 실행하지 않는다. 사용자 앱은 그대로 둔다. 표의 중앙값은 세 프로세스 비율의 중앙값, 범위는 그 최솟값/최댓값이다. P90/P10은 양쪽 표본의 가장 큰 편차다. 세 비율이 모두 1.10 이하이고 P90/P10도 1.30 이하인 항목만 이 독립 조건 통과로 표시한다.

문자열은 copy constructor 대 copy constructor와 pointer+length 생성 대 pointer+length 생성을 분리했다. 두 항목 모두 noinline 바이트 소비 함수로 모든 바이트를 읽으며 소비 함수 비용도 포함한다. 이전의 view 생성 대 STL copy, 또는 길이/중간 1바이트만 소비한 결과와 직접 전후 비교하지 않는다. 일반 해시맵은 tombstone 삭제로 바뀌었으며 적재율 0.5가 기본이다. 메모리 예산이 같은 STL 비교가 아니다. 슬롯/sequence/LRU/age/arena는 특정 용도의 대조다. STL과 API·메모리·실패 조건이 다르므로 일반 대체 우위로 확대하지 않는다. TLSF는 사용자 제공 arena의 128B 순차 할당/해제 대 CRT new/delete이며 초기 arena 확보 비용·실제 엔진 heap 분포는 포함하지 않는다.

§03

API·수명 계약

배열은 noexcept move 또는 copy 경로에서 재할당 실패 시 원본 값을 보존한다. move-only throwing move와 erase 중 throwing assignment는 기본 보장이다. 중간 insert는 별도 버퍼를 사용하므로 주소를 무효화하며 항상 무할당이라고 가정하지 않는다. 맵 재해시는 noexcept key/value move 또는 양쪽 copy 가능을 요구한다. hash/equality 및 저장소와 함께 전파되는 allocator/policy 복사·대입은 noexcept여야 한다. 비복사 값 컨테이너의 복사는 컴파일 단계에서 거부한다.

string은 23B SSO이며 UTF-8 바이트·내부 NUL을 보존한다. 대소문자 변환/유니코드 정규화는 범위 밖이다. 사용자 resource는 컨테이너보다 오래 살아야 하며 fixed/monotonic reset/release는 그 저장소를 쓰는 객체를 파괴한 뒤 호출한다. allocator는 외부 컨테이너 저장소와 함께 전파하고 내부 값의 별도 allocator까지 자동 전파하지 않는다.

slot/atom 핸들은 테이블 수명 안에서만 유효하다. clear/erase 후 generation을 검사하고 다른 owner 핸들을 거부한다. generation wrap 시 슬롯을 퇴역시키거나 atom 재사용을 중단한다. sequence/age는 모듈러 uint64 wrap을 허용하지 않는다. LRU accessor/링크 저장소는 리스트보다 오래 살아야 하고 한 링크는 한 리스트에만 속한다.

일반 컨테이너와 resource는 자체 동기화를 하지 않는다. TLSF는 64비트 고정 사용자 arena, 물리 이웃 병합, 64x16 비트맵, 16B 블록 정렬이며 상위 크기 클래스 반올림/fragmentation으로 실패할 수 있다. CRT로 자동 fallback하지 않는다. hash_bytes는 자체 블록 혼합으로 변경했고 영속 파일 포맷/보안 해시로 사용하지 않는다. 작은 정렬은 안정 insertion/merge, 큰 정렬은 LSD이며 noexcept 이동·대입·키 추출을 요구한다.

§04

수용 경계

느린 항목과 편차 초과 항목을 평균으로 숨겨 전체 통과시키지 않는다. 엔진 PPL 별칭 및 실제 소비자는 변경하지 않았다. 락 프리 큐의 기존 성능 보고서는 별도이며 이번 일반 컨테이너 확장 결과로 대체하지 않는다. 문자열/새 타입의 보완과 실제 소비자별 메모리·프레임 수용을 마친 범위부터 적용한다.

이 보고서 작성 시점에는 고정 용량 MPSC 전용 타입을 제공하지 않았다. 예약 후 멈춘 생산자가 소비자를 막는 단순 sequence 링을 lock-free라고 추가하지 않았다. 당시 다중 생산자용 선택 타입은 기존 FAA lock_free_queue다. GCC/macOS/ARM64 및 OS 간 성능 행렬, 실제 엔진 씬·종료 수용은 남아 있다.

§05

2026-10-26 후속 구현

고정 값 풀과 취소 가능한 FAA publication ring의 bounded_mpsc_queue를 추가했다. 대형 배열 재할당, 해시맵 miss 조회, 측정 편차를 분리한 후속 검증은 MPSC·배열·편차 보고서가 정본이다. 위 표의 역사적 측정값은 수정하지 않는다. 후속 문자열 비교는 양쪽 복사 생성자를 같은 방식으로 호출하고 pointer+length 생성은 별도 조건으로 측정하므로, 이전 복사 표와 직접 이어 붙이지 않는다.
