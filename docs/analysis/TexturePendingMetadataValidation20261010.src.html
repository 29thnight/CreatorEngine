세부 계약·원래 분석과 당시 측정 기록

검증 방법과 범위

실제 Inspector의 Maximum Dimension 숫자 입력으로 자동 저장을 대기시킨 뒤, assets.texture.pendingprobe가 owner thread에서 400ms 전에 외부 삭제 또는 손상을 주입했다. 숫자 편집과 Reload는 실제 Editor UI 조작이고, 파일 실패 주입은 .texture-auto-ui-race 표시가 있는 격리 프로젝트의 fixture.png.meta에 한정한다. 검증 모드 delete/corrupt와 실행 도우미의 해당 선택지를 추가했다. 제품 저장 경로의 구현은 이번 검증에서 변경하지 않았다.

대기 항목이 소진된 후 750ms 동안 외부 상태를 확인한다. 삭제는 파일이 없는 상태, 손상은 주입한 bytes 그대로여야 하며 자동 저장 오류가 있어야 성공이다. 각 모드는 구성별 한 번의 제어된 경합이다. 반복/장시간, 최종 디스크 비교 이후 쓰기, 삭제·손상과 동시에 종료하는 경합, 다중 창/배율, GPU pixel oracle은 포함하지 않는다.
