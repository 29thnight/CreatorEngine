# 통합 큐 실행의 물리 접근 계약

기준: master `493536e300e274cbf59989cdd62b20310c8ae64f`의 소스와 실제 호출 배선. 이번 개정에서는 빌드·테스트·GPU 실행을 하지 않았다. 구현 존재와 실행 수용을 구분한다.

## 이 문서의 역할

통합 큐 실행의 물리 접근 계약에 관한 과거 단계별 기록을 현행 계약으로 다시 정리한다. 공통 용어·수명·실행 모델은 [RenderGraph 정본](../plans/RenderGraphDependencySchedulingPlan.md)을 따른다. 날짜가 붙은 파일명은 링크 호환을 위해 유지한다.

## 현재 구현과 호출 경로

BuildQueueDependencies는 같은 상태·queue의 immutable read를 묶고 writer·상태/ownership 변경 시 reader들을 join한다. SubmitQueues는 이 계획과 공통 기록/body/barrier 경로를 사용한다. DeclareComputeCompatible는 pass 저자의 명시적 계약이며 state 모양만 보고 추론하지 않는다.

## 변경·검증 기준

SSAO/SSGI/HZB/post 같은 compute 작업도 실제 입력 의존성과 queue에서 합법적인 state가 있어야 이동할 수 있다. owned aliasing 금지는 유지하며 lifetime safety를 예측 이득과 교환하지 않는다.

과거 로컬 Build/Artifacts 경로의 수치와 완료·기성 표시는 이번 소스 감사에서 재검증하지 않았으므로 현재 통과 결과로 옮기지 않는다. 제품 기본값, 특정 fixture 성공, 여러 backend의 제품 수용은 각각 판정한다.
