# Transient buffer와 placed heap 공유

기준: master `493536e300e274cbf59989cdd62b20310c8ae64f`의 소스와 실제 호출 배선. 이번 개정에서는 빌드·테스트·GPU 실행을 하지 않았다. 구현 존재와 실행 수용을 구분한다.

## 이 문서의 역할

Transient buffer와 placed heap 공유에 관한 과거 단계별 기록을 현행 계약으로 다시 정리한다. 공통 용어·수명·실행 모델은 [RenderGraph 정본](../plans/RenderGraphDependencySchedulingPlan.md)을 따른다. 날짜가 붙은 파일명은 링크 호환을 위해 유지한다.

## 현재 구현과 호출 경로

CreateBuffer는 kind와 desc를 가진 graph-owned transient를 선언한다. CreateAliasedTransients는 생존 수명과 allocation compatibility를 보고 같은 native heap의 placed resources를 만든다. AliasedGroup이 native heap과 resource entries를 함께 소유한다.

## 변경·검증 기준

정렬·compatibility·겹치는 lifetime·초기 clear·alias barrier를 검사한다. graph completion 전에 group을 free cache로 돌리지 않는다.

과거 로컬 Build/Artifacts 경로의 수치와 완료·기성 표시는 이번 소스 감사에서 재검증하지 않았으므로 현재 통과 결과로 옮기지 않는다. 제품 기본값, 특정 fixture 성공, 여러 backend의 제품 수용은 각각 판정한다.
