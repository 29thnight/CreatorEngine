LX HDR 최초 발행 전환 — 2026-10-12

일반 Deferred 조명 패스를 삭제했다. 현재 렌더러는 LX.Scene.Color 노드에서 LX 소유 HDR 타깃을 생성·초기화하고 LX 셰이딩을 수행한다. 기존 조명 결과를 받아 보정하는 배선은 없다.

  • EnhancedDeferredPass.cpp/.h, Deferred.slang/.meta와 프로젝트 등록을 삭제했다. 라이브 노드, 패스 멤버, IBL 바인딩, 가짜 Deferred 광원 한도 표시도 제거했다.
  • SceneHost::DeclareHdrTarget가 HDR 생성과 유일한 최초 클리어를 소유한다. 빈 장면·아직 그릴 LX 머티리얼이 없는 장면도 같은 코드로 초기화한다. 호환 패스나 대체 조명 셰이더를 추가하지 않았다.
  • LX.Scene.Color는 LitColor의 writer다. 굴절을 위해 공유 표면·깊이 수정 계약은 유지한다. 이후 소비자는 LX HDR을 수정한다.
  • Forward 그림자 입력 설정은 Forward 노드로 옮기고 Shadow.Map read를 명시했다.
  • 쿠킹 바이트 형식은 변경하지 않았다. 새 호환 포맷을 만들지 않았으며, 실행 검증 프로젝트에는 현재 셰이더만 복사하고 모델을 실제로 재임포트했다.

§01

테스트 변경

  • DX12 RenderGraph 선언 테스트는 실제 LX HDR 생성 함수를 사용한다. 최초 writer의 입력 없는 단일 쓰기, SkyBox의 이전 버전 독자와 WAR 의존성을 검사한다.
  • 그림자·표면 GraphSceneFixture의 별도 HDR 생성 코드를 LX 소유 코드로 바꿨다.
  • Raster/Matched 머티리얼 도구와 Decal·SSS·굴절·Volume .inl에서 Deferred 참조를 제거했다. 삭제된 표면 패스의 Initialize/Prepare API를 호출하지 않고 리소스를 선언한다. 굴절·Volume의 일반 표면 가림체는 LX 머티리얼 드로우로 옮겼다.
  • 삭제된 indexed 그림자 배치에 의존하던 csm_legacy_batch_tests.inl과 호출·검증 입력 등록을 제거했다. 현재 에디터의 compute 목록·메시 셰이더 그림자 검증이 실행 증거다.
  • ABI 검사에서 삭제된 Deferred 셰이더를 제외하고 현재 검사 수 compiled=50 rejected=18을 확인했다.
  • 실제 캡처 검사에 Deferred 부재, LX HDR 클리어 1회, 빈 장면의 LX 출력 RGBA 정확히 0, LX 단계의 유한한 조명 픽셀을 추가했다.

실제 에디터 캡처의 최초 LX 출력과 컴파일 그래프를 검사했다. GPU validation 실행은 성능 측정이 아니다. 별도 Raster/Matched 도구는 Release 빌드를 확인했으며, 그 도구의 특수 머티리얼 전체 GPU 행렬은 이번에 재실행하지 않았다. Vulkan 실행 수용은 계속 PHASE 4.9 범위다.

변이 검사 4건도 예상 거부를 확인했다: Deferred 노드 삽입, HDR 클리어 삭제, HDR 클리어 중복, 빈 LX HDR의 첫 값 오염. 오염 검사는 독립 복사본을 사용했고 예상 거부 후 복제 픽셀을 삭제했다.

첫 Release 실행의 초기 판정은 거부였다. 당시 검사가 SkyBox까지 합성한 최종 HDR을 검정으로 요구했기 때문이다. 원본을 보존해 LX 직후 출력은 정확히 0임을 확인했고, 검사 지점을 실제 LX 초기화 출력으로 수정했다. Debug와 Release를 수정된 검사로 다시 정상 실행해 통과했다. 최초 실패 판정은 덮어쓰지 않고 Release-Initial/review.json에 원인을 기록했다.
