변경한 실행 경로

  1. EnhancedRenderGraph::RecordSoftware가 worker target별 명령 목록을 기록한다. 값·span payload는 target의 단일 writer 아레나에 복사한다. 밀봉한 batch를 bounded FIFO에 넣고 RHI thread가 번역·제출한다. GPU 완료 수명은 별도 completion fence와 owner token으로 보존한다.
  2. render_arena_resource는 pmr를 사용하지 않는 단조 증가 아레나다. backing block은 vendored mimalloc v3.5.3에서 얻는다. 정렬된 offset 할당에는 mutex·atomic·가상 호출이 없다. 64KiB 이상 block 주소는 안정적이고 마지막 owner 뒤 reset으로 재사용한다.
  3. render_arena_allocator<T>는 중첩 vector와 map value에 같은 writer domain을 전달한다. allocator를 명시하지 않은 일반 복사는 독립 mimalloc 저장소로 만들어 원본 프레임이 끝난 뒤에도 유지된다. 서로 다른 domain의 move assignment는 목적지 저장소를 지킨다.
  4. RenderArenaPool의 free set은 원자 포인터 슬롯 8개다. 반환자가 독점 상태에서 reset한 뒤 release CAS로 게시한다. 획득자의 acquire exchange가 포인터 소유권과 초기화 결과를 가져간다. intrusive next link를 읽지 않으므로 제거·재게시가 ABA 링크로 이어지지 않는다. 캐시의 backing capacity는 16MiB로 제한하고 넘친 set은 즉시 해제한다. 원자 포인터와 size_t가 lock-free인지 compile-time assertion으로 검사한다.
  5. 소프트웨어 명령 블록도 같은 비-pmr 풀을 사용한다. 명령별 할당은 현재 청크의 정렬 계산·커서 증가만 수행한다. 풀 접근과 backing 통계 갱신은 64KiB 이상 청크를 활성화할 때만 수행한다. 범용 아레나 호출과 전체 통계 복사를 명령마다 반복하지 않는다. 마지막 번역·취소 소비자가 반환한 뒤 다음 기록에서 재사용한다. 다른 batch의 live block을 빌리지 않는다. 명령 헤더의 payload 포인터를 1바이트 offset으로 치환해 헤더를 32→24바이트, Draw를 48→40바이트로 줄였다. 명령·payload의 실제 정렬 중 큰 쪽을 사용해 Draw를 저장소에서도 40바이트 간격으로 배치한다.
  6. DX12GpuProfiler::MergeSlices는 매 프레임 unordered_map node를 만들고 지우던 경로를 연속 open-addressing 버킷으로 바꿨다. 버킷·병합 scratch·출력 문자열은 재사용한다. 빈 버킷은 0, 값은 scratch index+1이다. 충돌은 선형 탐사하며 최대 load factor는 0.5다. 이름은 호출 중에만 빌리고 성공·예외 반환 모두 scope guard가 제거한다. busy 구간 정렬과 slice 순회는 span으로 Debug STL iterator 등록 락을 없앴다.

Draw·RDG의 지역 scratch 컨테이너는 프레임 lease의 아레나를 사용한다. 새 코드에서 명령마다 지역 heap 컨테이너를 만들지 않는다. 캐시 warm-up 뒤 raw backing block을 재사용하고, 컨테이너의 비자명 소멸자를 먼저 실행한 뒤 raw storage를 reset한다. pool 교환의 lock-free 보장과 cold allocation·shared_ptr 수명 관리의 비용은 각각 다른 동작이다.

RHI FIFO의 owner 등록·실패·장치 수명 전이와 condition-variable 알림은 기존 동기화를 유지한다. 티켓의 ready polling은 acquire atomic load를 사용한다. 프레임 수명 경계를 단일 producer FIFO라고 가정해 임의로 SPSC 큐로 바꾸지 않았다.

재질 전체 표면 suite는 범위를 패킷 계획 전용 검사로 전환하면서 중지했다. 전체 재질 표면 suite의 통과로 집계하지 않는다.

재실행 명령:

pwsh -NoProfile -File Tools/regression/verify-rhi-software-commands.ps1
pwsh -NoProfile -File Tools/regression/verify-rhi-software-native.ps1 -OutputDirectory <새 디렉터리>

verify-rhi-software-commands.ps1은 MSVC /Od /MDd /W4 /WX로 probe를 빌드한다. mimalloc C 소스는 기존 프로젝트와 같이 /O2로 빌드한다. 엔진 Debug C++의 최적화 수준이나 iterator debug 설정을 낮추지 않았다.

제품 번역은 DX12 graphics queue의 serial translation이다. Vulkan adapter 타입은 있지만 Vulkan 제품 경로 전환과 병렬 번역은 구현 범위에 포함하지 않았다. 소프트웨어 기록은 기존과 같이 명시적 환경 변수로 켠다.

참고 근거

CPU Performance Engineering의 측정·동시성·allocator 지침을 확인했다. 현재 연결된 MCP 도구 목록에는 해당 서버가 없어 원본 자료를 사용했다. 저장된 ETW의 std::_Lockit, iterator orphan/adopt, heap 할당 스택과 현재 RHI 소스를 연결해 변경 대상을 골랐다. 전역 Debug 검사 해제 대신 수명별 재사용과 연속 저장소로 해당 호출을 줄였다.
