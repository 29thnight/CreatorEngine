현재 변경의 프레임 성능은 측정하지 않았다. 빨라졌다는 수치를 제시하지 않으며 성능 이득을 논한다면 추정이다. 실패 복구의 queue는 기존 persistent 버퍼다. 새 지역 동적 컨테이너를 추가하지 않았다. 버퍼 capacity 증가나 메모리 부족에서 할당이 실패하면 이번 복구 역시 성공을 보장하지 않는다.

CPU commit은 GPU 완료가 아니다. 큐에 들어간 변경은 렌더 소비·실제 GPU 완료를 별도로 확인한다. 예외 메시지는 instance·generation을 남기고, 복구된 dirty는 다음 commit을 기다린다. 영구 실패는 반복 재시도할 수 있으며 bounded retry 정책은 이번 변경에 추가하지 않았다.

광원 압축 코드·복잡도·4,096개 입력 대조·측정 조건

Scene::EndFramePass는 매 프레임 DestroyLight를 호출한다. 기존 구현은 함수 지역 unordered_map으로 슬롯별 노드를 만들고 지역 vector를 reserve한 뒤 lightSlots에 move했다. 라이트가 변하지 않은 프레임에도 두 지역 컨테이너를 다시 구성했다. 수정본은 SceneRenderRegistryState의 lightSlotRemap capacity를 재사용하고, 기존 lightSlots를 축소·채움으로 제자리 압축한다. 엔진 수정 코드에 지역 동적 컨테이너를 추가하지 않았다.

연산량은 슬롯 수 S와 등록 광원 수 L에 대해 O(S+L)이다. scratch 메모리는 최대 도달 슬롯 수 H에 대해 H개의 size_t capacity를 보유하며 Scene 수명 종료 시 해제된다. 초기 9개 타입별 vector 중 5개를 제거하고 슬롯 remap용 재사용 vector 1개를 추가했다. 첫 사용·최대 슬롯 수 증가 시 resize가 할당할 수 있다. 이미 확보한 capacity 내의 반복 호출은 새 할당을 요구하지 않는다. 상시 O(S+L) 순회 자체는 유지했다. 첫 방향광의 StaticShadows 지정이 매 호출의 기존 동작이기 때문이다.

void Scene::DestroyLight()
{
    auto& slots = m_renderRegistry->lightSlots;
    auto& remap = m_renderRegistry->lightSlotRemap;
    remap.resize(slots.size());
    size_t liveCount = 0;
    bool isFirstDirectional = false;

    for (size_t i = 0; i < slots.size(); ++i)
    {
        remap[i] = 0u != slots[i] ? liveCount++ : std::numeric_limits<size_t>::max();
    }

    for (auto& comp : m_renderRegistry->lights)
    {
        if (!comp) continue;

        int& lightIndex = comp->m_lightIndex;
        auto& lightType = comp->m_lightType;
        if (lightIndex >= 0 && static_cast<size_t>(lightIndex) < remap.size()
            && remap[lightIndex] != std::numeric_limits<size_t>::max())
        {
            lightIndex = static_cast<int>(remap[lightIndex]);
        }

        if (!isFirstDirectional && lightType == LightType::DirectionalLight)
        {
            isFirstDirectional = true;
            comp->m_lightStatus = LightStatus::StaticShadows;
        }
    }
    slots.resize(liveCount);
    std::fill(slots.begin(), slots.end(), uint8_t{1});
}
