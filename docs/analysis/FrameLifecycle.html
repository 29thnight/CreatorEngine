프레임 구조 · CreatorEngine

한 프레임은 스레드 셋을 건너고, 화면에는 GPU가 끝낸 지난 슬롯이 뜬다

게임 스레드가 시뮬레이션을 돌리고 패킷을 밀봉해 발행한다. 렌더 스레드가 렌더 큐에서 그것을 꺼내 GPU에 제출한다. 표시 스레드는 펜스가 끝난 슬롯을 화면에 올린다.

렌더 패스

뷰 하나는 패스 열여덟 개를 차례로 선언한다

PostChain 안은 블룸 사용 시 BloomThreshold → BloomDown → BloomUp, 그다음 Uber(톤 매핑) → Output(FXAA) 순서다. 선언이 끝나면 graph.Compile → RecordParallel(작업자 넷) → EnqueueRecordedBatch → dx12.EndFrame 으로 제출한다.
