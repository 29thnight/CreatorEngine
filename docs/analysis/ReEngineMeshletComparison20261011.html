2026-10-17 공유 물리 풀·전역 페이지 정책·packing·증분 전송

자산별 고정 가상 주소와 장치별 공유 64 MiB 물리 heap을 연결했다. 완료·비참조 캐시의 선택 페이지부터 전역 우선순위/최근 사용 순서로 퇴거하며 활성 페이지는 보호한다. 패킷은 16바이트 정렬로 packing하고 유지된 패킷을 건너뛰며 메타데이터 변경 구간·신규/재매핑 패킷만 전송한다. Debug/Release 5모드·Editor 통합·39노드 배선 검증을 통과했다. 최종 결과와 잔여 범위는 현재 검증을 따른다. 성능 측정은 하지 않았다. 아래 기존 비교와 수용 기록은 각 작성 시점의 이력이다.

Analysis · 2026-10-11

RE ENGINE 메시렛 파이프라인과 CreatorEngine 지오메트리 경로 비교

출처: REAC 2025 RE ENGINE 메시렛 렌더링 파이프라인 발표 번역본(Dragon's Dogma 2, Monster Hunter Wilds). 비교 대상: GpuMeshletVisibility, GpuGeometryOcclusion, GpuGeometryVisibility, EnhancedGBufferPass, EnhancedShadowPass, MaterialGraphSceneHost, Experiment/MeshletData.h, Experiment/MeshLodData.h.

이전 기록: 2026-10-16 CEGE9 저장·소비자 전환2026-10-16 현재 구현 · SceneHost 39 / CEGE9

아래 본문은 10월 11일의 역사적 비교다. 현재는 GPU ring·JOB_COUNT·준비된 뷰 공유, 그림자 2단계 컬링·정적 캐시, 속성별 양자화·GPU 직접 복원, Reserved Resource 풀·GPU 요구·장치 VRAM 성장 예산·메타데이터 콜드 로드와 Editor 소비자 전환을 연결했다. 후속 5·6단계는 CEGE의 원본 본문과 Editor generation의 model.cemc를 제거하고 구형 CEGE/generation 리더·비활성 collider 작업 연결을 정리한다. CEGE9는 메타데이터와 QMC2 페이지만 저장하며 정확한 충돌 위치·인덱스는 별도 CECP로 지연 소비한다. schema 2 generation은 기하 배열 없는 metadata.cemc를 읽는다. shader 39 / GPU schema 6은 유지한다. 최신 빌드·정확성 결과는 현재 검증과 소비자 정책을 따른다. 자산 간 물리 타일 재분배·대규모 스트레스·RE 비공개 인코딩 동일성·Vulkan·성능 수용은 별도다. 성능 측정은 하지 않았다.

요약
  • 현재 표면·그림자는 LX 단일 배선이다. 일반 GBuffer 표면 구현과 전용 GPU 메시렛/LOD 컬링 모듈은 삭제했다.
  • LX 카메라 오클루전은 현재 프레임 깊이 선행 방식이다. RE의 이전 HiZ 기반 2단계 재검사는 후속이다.
  • 가시성 버퍼, 소프트웨어 래스터라이저, 바인드리스 머티리얼이 없다.
  • 그림자 캐스터는 LX 경로로 통일했다. 2026-10-12 사용자 지시로 DX12 compute 메시렛 생존 목록과 indirect 소비를 구현했다. 정확도·변이·성능 검증 범위는 현재 실행 기록을 따른다. Vulkan은 PHASE 4.9에서 검증한다.

04도입 우선순위 제안

  1. 그림자 패스에 메시렛 단위 GPU 컬링
    사용자 지시로 DX12 compute 사전 컬링을 구현하고 기준선·3장 동치·누락 변이·반복 성능을 재검증한다. Vulkan 실행·교차 비교는 PHASE 4.9에 이관한다. 계획: ShadowMeshletGpuCullingPlan.
  2. 2단계 오클루전 (이전 프레임 HiZ + 재검사)
    오클루더 지정 의존을 없앤다. 기존 PrepareOcclusionRecheck를 2단계 쪽으로 확장할 수 있다.
  3. 컬링 작업 분배 개선
    CPU의 쌍 펼치기를 GPU 측 확장으로 옮겨 65535 상한과 CPU 비용을 없앤다. 대형 HLOD 대비.
  4. 속성 양자화·압축
    메모리와 대역폭 절감. 쿠커(CookedModelCodec)만 바꾸면 되는 독립 작업이다.
  5. 가시성 버퍼 + 바인드리스 + SW 래스터
    효과는 가장 크지만 머티리얼 그래프, 미분, 데칼까지 재설계하는 장기 과제다. RE도 두 타이틀에 걸쳐 단계적으로 도입했다.

05한계

  • 원문 PDF의 성능 표 수치(CPU/GPU 시간, 메모리)는 텍스트 추출 과정에서 빠져 비교하지 못했다.
  • 본 비교는 소스 구조 검토다. 그림자 계획에는 합성 장면의 제한된 Release 역사적 측정이 추가되었으나, 현재 빌드의 성능·전체 픽셀 정확성 수용은 아니다. 2026-10-11 DX12 Debug/Release의 5개 회귀와 backOff 제거 변이 거부는 현재 기준선에서 확인했다. 두 합성 메시·두 포즈의 그림자 맵 3장 비트 동치와 보이는 사각형 메시렛 누락 변이 거부·정상 대조군도 당시 D/R에서 확인했다. 12개 합성 장면의 알파 임계값·면 정책·변환·경계·먼 캐스터·다중 메시렛도 해당 보고서의 D/R에서 동치·변이 거부를 통과했다. 텍스처 알파 패턴 등 일반 수용은 남아 있다. 오클루더 선행 패스 비용은 실측하지 않았다.
  • 2026-10-12 후속 반복 측정: 4096 계측 슬롯으로 큰 장면의 1710개 구간 누락을 해결하고, 현재 Release 3개 합성 장면·총 24회 기록을 검증했다. GPU 비용 비교는 변동성 기준을 통과하지 못해 성능 이득과 compute 착수는 수용하지 않는다. 위 동치·변이 결과는 각 보고서의 당시 binary 증거이며 새 계측 빌드의 재실행 결과와 구분한다.
  • DX12/Vulkan 그림자 실행·리소스·픽셀 비교는 PHASE 4.9에서 수행한다. 현재 LX 작업의 완료 조건에 포함하지 않는다.

2026-10-12 사용자 지시로 DX12 compute 생존 목록을 구현했다. 최종 D/R 선택 정확도·변이·회귀는 통과했으며 Release 3장면·24회 compute 포함 성능 이득은 미수용이다. PHASE 4.9 Vulkan 이관은 유지한다. 구현과 현재 검증 기록.

2026-10-12 현재 구조 갱신: 일반 GBuffer 표면 구현·구경로 테스트·비교 토글을 삭제하고 LX 단일 배선으로 전환했다. Scene ABI 21의 강제 리임포트·재쿠킹 계약을 적용한다. 이전 동치·성능 판정은 당시 바이너리 기록이다. 실제 삭제 목록·현재 배선·검증.

메시렛 계약 후속: 현재 LX는 쿠커의 단일 클러스터·원본 삼각형 ID를 사용하며 런타임 재클러스터링을 삭제했다. Scene ABI 22 · CEMC 13 · geometry artifact 2 · meshlet profile/builder 2로 갱신했다. 이전 산출물은 강제 리임포트·재쿠킹 대상이다. 현재 데이터 계약과 검증.
