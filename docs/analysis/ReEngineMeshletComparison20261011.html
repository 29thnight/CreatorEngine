비교 자료의 범위

이 경로는 2026-10-11 RE ENGINE 비교 보고의 후계다. 외부 엔진의 비공개 구현이나 최신 게임 상태를 확인하지 않았으므로 RE ENGINE의 세부 동작·우열을 현재 사실로 단정하지 않는다. 여기서는 비교에 필요한 CreatorEngine의 실제 producer/consumer와 수명 기준을 고정한다.

외부 발표와 비교할 때는 발표 버전·장면·하드웨어·render path를 별도 출처로 붙여야 한다. 이름이 같은 meshlet이나 HZB가 같은 알고리즘·성능을 뜻하지 않는다.

현재 제품 파이프라인

EnhancedSceneRenderer는 METEOR Geometry → Cull.First → Occluder → Cull.Final → Surface를 배선한다. Shadow는 Geometry를 독립 소비한다. current/previous/shadow pose는 geometry owner가 준비하고 object-space 출력은 world transform이 다른 instance에서 공유한다.

SceneHost는 meshIndirect와 cooked meshlet을 요구한다. general visibility helper의 nullable 결과는 여기에서 CPU/direct route를 제공한다는 뜻이 아니다. 옛 “모든 group을 mesh shader에서만 거절”이라는 단계 설명을 최신 전체 경로로 읽지 않는다.

current depth와 history의 구분

current-frame HZB는 앞서 선언된 같은 view의 standard-Z depth에서 만든다. 소비자가 다시 쓰는 depth로 자신의 visibility를 판단하는 feedback은 피한다. history는 device·view·revision·completion을 보존하고 현재 graph에 recording-local read로 가져온다.

카메라 가시성으로 shadow 가시성을 대체하지 않는다. 불확실한 bound나 projection은 conservative하게 다뤄야 하며 custom pixel depth/depth bias는 helper의 명시된 HZB 입력 가정 밖이다.

비교해야 할 비용과 자원

visibility Frame은 candidate·visible IDs·indirect args를 recording별로 소유하고 submitted GPU 작업이 끝날 때까지 유지한다. 서로 다른 view/frame이 같은 buffer를 덮어써 절약한 것처럼 보이는 구현과 비용을 비교하면 안 된다.

DispatchMeshIndirect 전용 bin과 DrawIndexedIndirect bin은 혼용할 수 없다. ordered meshlets와 preserved instance stream은 투명 순서를 유지하는 별도 계약이다. 성능 비교는 같은 visible work·quality·history validity와 실패 정책을 고정해야 한다.

미검증과 후속

이 문서는 새로운 capture나 GPU timing을 만들지 않았다. 과거 측정 이미지는 당시 evidence로 유지한다. 현재 제품 품질·backend parity·LOD 전환·occlusion false-negative·device-loss는 별도 gate다. 최신 계약은 GPU 기하 배선과 graph 수용 경계에서 이어진다.
