# Aliasing 채택과 메모리 판정

기준: master `493536e300e274cbf59989cdd62b20310c8ae64f`의 소스와 실제 호출 배선. 이번 개정에서는 빌드·테스트·GPU 실행을 하지 않았다. 구현 존재와 실행 수용을 구분한다.

## 이 문서의 역할

Aliasing 채택과 메모리 판정에 관한 과거 단계별 기록을 현행 계약으로 다시 정리한다. 공통 용어·수명·실행 모델은 [RenderGraph 정본](../plans/RenderGraphDependencySchedulingPlan.md)을 따른다. 날짜가 붙은 파일명은 링크 호환을 위해 유지한다.

## 현재 구현과 호출 경로

Live RenderOnce의 CREATOR_RENDERGRAPH_ALIASING 기본은 false다. owned queue와 aliasing 동시 사용은 명시 오류다. aliasing 구현이 있다는 것과 retained product memory가 실제로 줄었다는 것은 별개다.

## 변경·검증 기준

한 graph의 placed allocation bytes만 보지 말고 retained/cached/leased heaps, 여러 view·in-flight graph·최대치·steady state를 비교한다. 해제 지연과 completion 이후 trim까지 측정한다.

과거 로컬 Build/Artifacts 경로의 수치와 완료·기성 표시는 이번 소스 감사에서 재검증하지 않았으므로 현재 통과 결과로 옮기지 않는다. 제품 기본값, 특정 fixture 성공, 여러 backend의 제품 수용은 각각 판정한다.
