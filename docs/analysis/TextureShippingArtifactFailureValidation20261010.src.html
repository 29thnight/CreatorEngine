수용 범위

최신 Release Shipping Player에서 PNG/HDR 독립 CECT의 누락·잘림4개를 catalog mount 단계에서 거부하고, 같은 fixture의 원본 artifact 복원 후 정상 DX12 렌더/종료를 한정 수용한다. 제품 수정·추가 빌드는 없다. 핵심 검사기는 Tools/regression/verify-texture-shipping-artifact-failure.ps1이다.

기준 정상 패키지는 §34의 ScenePkg-Release-Shipping-cea0ff2f5dee4299a4b3db65ec23e7aa/Stage/Game-864cc3d45c3347138f5e347d065a95e1이다. 이전 실패 candidate의 보존된 Merged 입력을 새 소유 fixture로 복사하고 현재 Shipping runtime을 별도 복사했다. 원본 이미지 없이 AssetPacker로 다시 암호화한 PAK를 실제 Player가 추출/마운트한다. 기존 정상 패키지를 수정하지 않는다.
