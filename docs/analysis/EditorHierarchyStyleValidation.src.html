현행 계약과 이 문서의 적용 범위

  • 제품 live graph는 명시적 버전과 dependency order를 사용한다. 선언 metadata 재사용과 dependency recording은 현재 구현 기반이다.
  • 소프트웨어 RHI의 frozen recording은 독립 target의 병렬 native 번역과 조기 sealed-batch handoff를 지원한다. 직렬 전용 번역·별도 C# SRP 저작 전환을 후속 필수 작업으로 두지 않는다.
  • queue/alias/hazard·reader join·retirement를 보존하고 실제 overlap·fallback·whole-frame 비용으로 RG8 채택을 판정한다.

이전 근거의 유효 범위

기존 세부 계약은 위 현행 구현과 모순되지 않는 범위에서 유지한다. 과거 수치·실행 통과·해시·장치 조건은 당시 기록이다. 로컬 산출물이 사라진 항목은 링크 대신 경로와 미보존 상태를 표시하며, 현재 master의 재실행 통과로 승격하지 않는다.

색상은 첨부 화면을 바탕으로 정한 근사값이며 S&Box의 공식 상수는 아니다. Material Symbols의 GameObject / Prefab 의미 아이콘과 기존 씬 그룹 표시를 유지한다. 기존 탭 표시와 저장된 Hierarchy 창 ID를 사용하며 이번 작업에서 탭 닫기 기능은 추가하지 않는다.

구현 경계

  • EditorStandardWindows.h의 배경 선언과 HierarchyStyleScope로 계층창 범위에만 색/간격을 적용한다.
  • 기존 TreeNodeEx, 재귀 탐색, 검색 필터, 선택 및 drag-drop 경로를 사용한다. 트리는 새 child의 ID 범위에 들어가므로 이전 프레임/실행의 개별 펼침 상태 이주를 보장하지 않는다.
  • 오브젝트 단축키는 트리에 포커스가 있고 텍스트 입력 중이 아닐 때만 처리한다. Delete는 최초 누름만 소비해 검색어 편집이 오브젝트 삭제로 전달되지 않게 했다.
  • 원래 동작이 없던 UI Button 생성 항목은 비활성 표시한다.
