병합 경계

이 작업은 통합 후보를 준비하는 단계이며 master 반영이나 원격 push를 수행하지 않는다. master가 위 기준 SHA에서 더 진행하면 다시 충돌과 영향을 검사해야 한다.

전체 run-all.ps1, Shipping 패키지, 모든 Commandlet 모드·HDR 실물 코퍼스·canonical 성능은 이번에 전수 재검증하지 않았다. 광원 게이트는 게임 스레드의 프록시 큐잉까지 확인하며 렌더 스레드 최종 적용을 대신하지 않는다. GUI 수동 조작과 canonical 성능의 기존 미확인 항목 때문에 Phase 14.5 전체 종결 보류는 유지한다. (2026-09-15 재정의: canonical 성능은 이 페이즈의 종결 조건에서 빠지고 소유가 PHASE 3.75로 돌아갔다. 남은 조건은 14.5 소유 게이트의 HEAD 재실행과 GUI 수동 조작 둘이며, 근거는 종결 검토의 재정의 절에 있다. 위 표의 실행 증거는 준비 트리의 것이므로 그 재실행을 대신하지 않는다.) 통합 전의 실행 증거는 Phase14_5Closure.md에 별도 보존했다.
