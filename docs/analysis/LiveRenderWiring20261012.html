METEOR 라이브 배선 읽기

기준: master 493536e300e274cbf59989cdd62b20310c8ae64f의 소스와 실제 호출 배선. 이번 개정에서는 빌드·테스트·GPU 실행을 하지 않았다. 구현 존재와 실행 수용을 구분한다.

시작점과 프레임 경계

Editor App과 PlayerApp이 BuildLiveFramePacket으로 scene epoch·proxy update·view key·camera snapshot·설정을 봉인하고 PublishLiveFrame에 넘긴다. EnhancedSceneRenderer가 소비하는 frame은 gameplay 객체를 렌더 callback에서 다시 조회하기 위한 포인터 목록이 아니다. render-owned LiveState는 view별 history·display slot·GPU 자원 owner를 유지한다.

현재 assembly 정본은 EnhancedSceneRenderer.cpp의 BuildPipelineDesc다. LivePipelineDesc는 typed slot과 reads/writes/modifies를 선언하는 영속 조립이고, EnhancedRenderGraph가 실제 프레임 자원·dependency·barrier·실행을 소유한다. C# pipeline 저작은 미래 목표다.

geometry에서 최종 표면까지

METEOR.Scene.Geometry는 현재·이전 object-space pose stream과 geometry identity를 발행한다. 인스턴스별 world 행렬을 나중에 적용하므로 동일 pose stream은 공유할 수 있다. Cull.First→Occluder는 history 가시성과 HW/SW 혼합 깊이를 만들고 Cull.Final은 현재 HZB에서 opaque recovery를 수행한다. blended는 frustum-only ordered 목록과 LayerWork를 사용한다.

Surface는 최종 visible identity·primitive remap·posed vertex·재질을 통해 GBuffer를 복원하고 decal을 적용한다. SceneSurfaceTargets는 MRT5+depth 생성·clear 책임만 갖는다. 예전 EnhancedGBufferPass와 EnhancedDeferredPass는 현재 live 조립의 소유자가 아니다.

LOD와 그림자

CEMC 15·geometry artifact 4·descriptor 5, meshlet profile/builder 2·LOD builder 3의 입력을 사용한다. spatial replacement hierarchy에서 허용 parent가 child 두 개를 원자적으로 대체한다. cooker는 child-before-parent인 disjoint binary tree 부분집합을 내며 GPU는 acceptable ancestor가 있으면 descendant를 다시 출력하지 않는다. 보존 경계와 simplification error는 독립 픽셀 수용을 대신하지 않는다.

Shadow는 Geometry와 light projection에서 독립적인 cascade 목록과 간접 명령을 만든다. C0/C1/C2 depth는 camera visibility/HZB와 독립이다. ShadowMath의 receiver 범위·snap·backOff와 실제 mask·sidedness·pose를 함께 확인한다. 선택 LOD와 posed stream을 재사용하는 것과 depth 결과를 프레임 간 캐싱하는 것은 다르며 후자는 현재 live 기능이 아니다.

조명에서 표시까지

History가 다음 프레임 camera HZB를 만들고 Temporal.Inputs가 motion/depth/mask를 준비한다. SSAO 다음 METEOR.Scene.Color가 첫 RGBA16Float HDR를 발행한다. SkyBox→SSGI→SSS→SSR→Volume→LightTiles→Blended→Sprite→VolumetricFog가 관련 surface/HDR를 소비한다.

Temporal.SpriteMotion과 Temporal.Upscale은 HDR temporal 입력·출력을 처리한다. PostChain과 SpatialPost 뒤 Temporal.DisplayInputs가 HUD 없는 입력을 보존하고 UI·host overlay·live_present가 표시를 완성한다. 기능별 비활성 경로와 unused producer culling이 있어 이 이름들이 매 프레임 모두 GPU 일을 한다는 뜻은 아니다.

Player의 frame generation은 presentation sink가 소유한다. renderer의 active TU, generated display와 source real frame, HUD-less/UI/depth/motion lifetime을 분리한다. Editor viewport에서 FG를 지원하는 것으로 표시하지 않는다.

안전한 확장점

SceneHost는 ExplicitVersioned·mesh indirect·정확한 cooked topology를 요구한다. generic visibility helper의 optional fallback을 제품의 CPU/direct surface 지원으로 해석하지 않는다. 단계 핸들은 정확한 graph·epoch·stage의 발행 결과여야 한다. raw resolve만 성공했다고 dependency와 lifetime이 증명되지 않는다.

기본 병렬 기록과 DX12 owned queue 제출을 구분한다. owned queue는 정확한 measurement·device/service generation·resource state·owner를 검증하며 aliasing과 동시 사용을 거부한다. imported state writeback은 Compile 때가 아니라 실제 upload admission을 확인한 OnUploadAccepted 때 반영한다. temporal history도 submit 성공 뒤 Commit한다.

이 페이지의 판정 범위

현재 구조는 소스와 실제 caller로 확인했다. 과거 날짜의 frame 수·픽셀 차이·GPU validation·성능을 이번 커밋의 실행 증거로 재게시하지 않는다. 모든 장치·재질 조합과 성능/품질은 별도 runtime 수용이 필요하다. 상세 정본은 같은 폴더의 RenderPipelineFlow.md와 design/GpuDrivenMeshletDxrWiring.md다.
