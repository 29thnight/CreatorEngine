METEOR 라이브 배선 현황과 RE 엔진까지 남은 작업

METEOR는 LX 머티리얼을 그리는 장면 렌더러다(정식 명칭은 MaterialGraphSceneHost.h 머리 주석 한 곳에 둔다). LX(Lattice eXperiment)는 노드 언어 자체(LX::Runtime, LX 머티리얼)를 가리키며 이후 비주얼 스크립트·BT에도 쓰인다. 대상은 DX12 라이브 경로이며 커밋되지 않은 작업 트리 기준이다. 배선 서술은 소스 구조이고, 04장의 실행 결과는 이번 정리에서 직접 돌린 검증이다.

요약
  • 노드 23개(+에디터 기여 4개)를 5단계(기하 → 래스터 → 불투명 조명 → 반투명·매질 → 시간·표시)로 정리했다. 그래프를 빌드하는 구조는 그대로다. 노드 순서는 슬롯 버전과 동순위 tie-break만 정하고, 실행 순서는 그래프가 리소스 의존성으로 컴파일한다.
  • 변환·컬링은 METEOR.Scene.Geometry·METEOR.Scene.Cull 노드가 맡는다. 이제 소비자의 부수 효과가 아니다. SceneHost가 Geometry → Cull → Shadow/Surface 선언 순서를 강제한다.
  • 구 EnhancedForwardPass를 삭제했다. 타일 광원 컬링은 EnhancedLightTilePass, 반투명 정렬·셰이딩은 SceneHost::DeclareBlendedStream이 맡는다.
  • 볼륨 합성은 반투명 앞 한 곳(METEOR.Scene.Volume)에서만 일어난다. SSS·SSR은 반투명 앞으로 옮겼다. 반투명면은 더 이상 SSS·SSR을 받지 않으며, 이는 의도된 화면 변화다.
  • Temporal 하드코딩을 없앴다. 소비자 목록 대신 각 노드가 consumes로 자기 조건을 밝히고, 캡처의 이름 비교 대신 displayResolutionOutput을 쓴다.

05관찰과 기존 문제

  • 기존 문제 1 — PostChain 병렬 기록과 GPU 기반 validation. 다른 작업이 PostChain 단계 패스에 DeclareRecordingIndependent를 추가했다. 그 뒤 GPU 기반 validation(CREATOR_DX12_VALIDATION=gpu)에서 PostChain.ToneMapped가 COMMON 레이아웃 그대로 UAV로 디스패치되는 오류가 난다. 그 한 줄만 빼고 다시 빌드하면 RG5_FINAL_GPU_OK로 통과함을 확인했고, 원래 코드로 되돌려 두었다. 이번 배선 정리와는 독립이다.
  • 기존 문제 2 — 머티리얼 프로브. Raster·Matched 프로브(MaterialRasterSurfaceProbe)는 새 API로 옮겨 빌드되지만, 공통 준비 단계에서 멈춘다. 합성 메시에 쿠킹된 메시렛 토폴로지가 없기 때문이다(메시렛 계약 전환 이후 필수). MaterialCommonConsumerProbe는 GBuffer 전환 이후 이미 컴파일되지 않는다. 프로브 안의 인자 평가 순서 버그(오류 메시지가 비어 보이던 원인)는 고쳤다.
  • 남은 LX 표기. 셰이더 진입점·Scene 패스 이름(LXSceneVS 등)과 LxMeshletGpuContract.slang은 쿠킹된 Scene 제품에 기록된다. 그래서 바꾸려면 Scene ABI를 올리고 재쿠킹해야 하며, 별도 작업으로 남긴다. 과거 분석 기록(docs/analysis/Lx*.md)은 당시 명칭 그대로 보존한다.
  • Forward ShaderMeta 자산. Forward*.shadermeta·ForwardShade.slang·ExperimentMaterialSealing의 Forward 축은 렌더러가 더 이상 소비하지 않는다. 에디터 코드 머티리얼 저작 체계와 엮여 있어 이번에는 남겼다.
  • 오래된 스크립트. verify-pipeline-composition.ps1(GBuffer·Deferred·Forward+ 노드 요구)와 verify-pbr-soak.ps1(GBuffer·Forward seal 필드)는 이전 전환부터 맞지 않는 상태다.
  • 성능. GPU 시간 비교는 전원 상태를 통제하지 않으면 판정할 수 없다(저활용 시 P5 강등). 성능은 각 작업과 함께 측정하며 원인을 찾는다.
