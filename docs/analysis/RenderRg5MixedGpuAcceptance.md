# 혼합 재질 GPU 수용 기준

기준: master `493536e300e274cbf59989cdd62b20310c8ae64f`의 소스와 실제 호출 배선. 이번 개정에서는 빌드·테스트·GPU 실행을 하지 않았다. 구현 존재와 실행 수용을 구분한다.

## 이 문서의 역할

혼합 재질 GPU 수용 기준에 관한 과거 단계별 기록을 현행 계약으로 다시 정리한다. 공통 용어·수명·실행 모델은 [RenderGraph 정본](../plans/RenderGraphDependencySchedulingPlan.md)을 따른다. 날짜가 붙은 파일명은 링크 호환을 위해 유지한다.

## 현재 구현과 호출 경로

현재 SceneHost는 sealed coverage와 ordered layer work로 opaque/masked/blended 및 특수 효과를 연결한다. 혼합 재질은 정확한 슬롯·resource versions와 shader entry contract를 충족해야 한다. 과거 24장면의 Code/Graph reference 성공을 현재 METEOR 전체 지원으로 볼 수 없다.

## 변경·검증 기준

alpha 0/1·중간값, depth 차폐, 순서 반전, refraction/SSS/volume 조합을 실제 attachment로 검사하고 unsupported volume도 거부 사례로 둔다.

과거 로컬 Build/Artifacts 경로의 수치와 완료·기성 표시는 이번 소스 감사에서 재검증하지 않았으므로 현재 통과 결과로 옮기지 않는다. 제품 기본값, 특정 fixture 성공, 여러 backend의 제품 수용은 각각 판정한다.
