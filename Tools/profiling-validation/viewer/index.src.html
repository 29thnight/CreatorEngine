Prepare Ready 동안 실제 CPU 점유 주체

분류PID · 프로세스TID · 이름관측 동적 우선순위CPU-ms

현재 시간 범위의 Prepare Ready 교집합 기준 상위 24개. 전체 주체와 구간은 JSON에 보존한다. Running은 인터럽트를 포함할 수 있는 CPU residency다. ThreadName 없는 과거 기록의 동일 프로세스 스레드는 역할을 추정하지 않는다.

GPU 큐 · CPU와 같은 시간축

뷰 · 큐 · 패스범위 내 합 ms호출원본 최대 ms

패스 합은 중첩 시 중복된다. 큐별 계측 구간 합집합과 첫~마지막 timestamp 폭은 상태 줄에서 구분한다. GPU 사용률·화면 FPS와는 다른 값이다. 0 tick 패스도 원본 0ms로 보존한다.

원본·정렬·표시 기준

미확인 상태는 Waiting이나 CPU idle로 치환하지 않았다. GPU 패스는 백엔드 타임스탬프다. 표시 FPS와 구분한다. QPC·UTC 기준으로 정렬했으며 스레드 상태 구간의 전체 길이를 0.005ms 오차 이내로 검사했다. .ceprof CPU 스코프 전체를 포함하며 GPU는 큐별 레인에 표시하고 CPU Running과 합산하지 않는다.
