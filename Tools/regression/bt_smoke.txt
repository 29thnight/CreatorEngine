# 행동 트리 스모크 시나리오 (트랙 BT — 관리 측 BT가 실제로 로드되고 도는가)
#
# ── 이 검사가 지키는 것 ──
#
#   BT가 **실제로 로드되고 틱한다**(트리 개수 · 노드 타입 · 틱 수 · 건너뜀 0).
#   그리고 네이티브↔관리 **경계 크로싱이 프레임당 1회 이하**여야 한다 — 그것이
#   BT를 관리 측으로 옮길 때의 계약이었다(BTManagedRedesign).
#   씬을 갈면 트리가 0으로 돌아가는지도 본다(누수·잔존 확인).
#
# ── CLI 저작으로 이전 (2026-08-20, 자산·게이트 CLI 이전 7·8/8 — 완결) ──
#
# 예전에는 저작 프리팹 BTProbe를 소환했다. 프리팹은 폐기 대상 폴더(Assets/Prefabs)에
# 있으므로 CLI 저작본으로 옮긴다.
#
# ★ **선행이 있었다 — CLI로 자산 참조를 설정할 수 없었다.** BehaviorTreeComponent는
#   m_BehaviorTreeGuid·m_BlackBoardGuid로 자산을 찾고 **이름 폴백이 없다**. 그런데
#   ApplyReflectedProperty가 FileGuid 타입을 지원하지 않아 *"지원하지 않는 프로퍼티
#   타입 (FileGuid)"*으로 떨어졌다(실측 -> 소환해도 트리 0개). BT만의 문제가 아니라
#   머티리얼·메시 등 **자산을 가리키는 모든 필드**에 걸리던 구멍이라 함께 메웠다.
#
# ★ **BT 그래프 자산(.bt·.blackboard)은 옮기지 않는다 — 폐기 대상이 아니다.**
#   §0.05의 폐기 대상은 저작 자산(프리팹 208 · 씬 12)이고, Assets/BehaviorTree의
#   BTProbe.bt/.blackboard는 **손으로 만든 게이트 전용 픽스처**다(노드 ID가
#   900000001~4로 규칙적이고 스크립트명이 BTProbeAuthoredValue처럼 검사 전용이다).
#   CLI에 BT 그래프 저작 표면이 없으므로(bt.status/bt.reset은 관측·리셋이다) 이
#   픽스처는 그대로 두고, 프리팹만 CLI가 만들어 guid로 가리킨다.
#
# 실행: Academy_4Q.exe --script <이 파일>
# 판정: verify-bt-smoke.ps1

wait 60
scene.new BTSmokeAuthor
wait 30

# ── 픽스처 프리팹 저작 (BT 자산을 guid로 가리킨다) ──
object.create BTSrc Empty
component.add BTSrc BehaviorTreeComponent
wait 20
object.property BTSrc BehaviorTreeComponent name BTProbe
object.property BTSrc BehaviorTreeComponent blackBoardName BTProbe
object.property BTSrc BehaviorTreeComponent m_BehaviorTreeGuid {{BT_GUID}}
object.property BTSrc BehaviorTreeComponent m_BlackBoardGuid {{BB_GUID}}
wait 20
prefab.create BTSrc BTSmokeProbe
# AssetMetaWatcher의 200ms 잠복(다른 게이트 주석 참고).
wait 90

# ── 깨끗한 씬에서 소환한다 (저작 원본이 트리 계수에 섞이지 않도록) ──
scene.new BTSmokeRun
wait 40

bt.status
prefab.instantiate BTSmokeProbe BTProbeA
wait 20
prefab.instantiate BTSmokeProbe BTProbeB
wait 20
prefab.instantiate BTSmokeProbe BTProbeC
wait 30
bt.status

bt.reset
play
wait 180
bt.status
stop
wait 30
bt.status

scene.new BTProbeEmpty
wait 60
bt.status

log.flush
quit
