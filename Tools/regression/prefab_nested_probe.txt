# 중첩 프리팹 정체성 시나리오 (SceneGraphRedesignPlan 트랙 P — P4-a)
#
# ── 이 검사가 지키는 불변식 ──
#
#   중첩 프리팹 인스턴스는 **자기 프리팹의 정체성**을 유지한다.
#   순수 자식(다른 프리팹의 인스턴스가 아닌 자식)은 바깥 프리팹의 guid를 물려받는다.
#   그리고 중첩 루트도 **등록부에 잡혀야** 한다 — 안 잡히면 그 중첩 프리팹을
#   고쳐도 UpdateInstances가 이 인스턴스를 영영 못 찾는다(확정된 결함 3).
#
# ── CLI 저작으로 이전 (2026-08-20, 자산·게이트 CLI 이전 3/8) ──
#
# 예전에는 저작 자산 NestedProbeParent.prefab(손으로 만든 픽스처, guid가 파일에
# 박혀 있었다)을 소환해 쟀다. 자산은 전부 폐기 대상이므로(§0.05) 그 자를 CLI
# 저작본 위로 옮긴다. 구조는 그 자산이 담고 있던 것과 같다:
#
#   NestedProbeLeaf.prefab                     <- 중첩될 리프 정의
#   NestedProbeParent.prefab
#     ├ NP_NestedLeaf   (NestedProbeLeaf의 인스턴스)  <- 중첩 루트
#     └ NP_PlainChild   (평범한 오브젝트)              <- 순수 자식
#
# ★ 저작 뒤 scene.new로 씬을 비우고 소환한다. 저작 원본이 씬에 남아 있으면
#   새 인스턴스의 자식이 이름 충돌로 "NP_NestedLeaf (1)"이 되어, 이름으로 조회하는
#   이 시나리오가 조용히 엉뚱한 오브젝트를 읽는다(P4-b 게이트에서 실측으로 걸린 함정 —
#   object.rename이 m_entityNameSet을 갱신하지 않는 것과 같은 뿌리다).
#
# ★ 등록 수는 **증가분**으로 판정한다. 저작 단계에서 리프를 한 번 인스턴스화하므로
#   등록부가 0에서 시작하지 않는다. "시작이 0이어야 한다"로 재면 저작을 시나리오
#   안에 넣는 순간 성립하지 않는다 — 기준선을 소환 직전에 다시 잡고 그 증가분을 본다.
#
# 실행: CreatorEditor.exe --script <이 파일>
# 판정: verify-prefab-nested.ps1

wait 60
scene.new
wait 30

# ── 리프 프리팹 정의 ──
object.create NPLeafSrc Empty
wait 10
prefab.create NPLeafSrc NestedProbeLeaf
# AssetMetaWatcher가 .meta를 쓰기 전 200ms를 sleep한다(RenderEngine/AssetMetaWather.h).
# wait는 프레임 단위라 벽시계 지연을 넘기려면 여유를 크게 잡는다.
wait 90

# ── 부모 구조: 중첩 인스턴스 + 순수 자식 ──
object.create NPRootSrc Empty
prefab.instantiate NestedProbeLeaf NP_NestedLeaf
wait 30
object.parent NP_NestedLeaf NPRootSrc
object.create NP_PlainChild Empty
object.parent NP_PlainChild NPRootSrc
object.create NP_RootRef Empty
object.parent NP_RootRef NPRootSrc
object.rootref NP_RootRef NPRootSrc
wait 20

prefab.create NPRootSrc NestedProbeParent
wait 90

# ── 깨끗한 씬에서 소환한다 (이름 충돌 회피 — 위 주석) ──
scene.new
wait 40

prefab.status
prefab.instantiate NestedProbeParent NP_Root_A
wait 30
prefab.status

prefab.objectguid NP_NestedLeaf
prefab.objectguid NP_PlainChild
prefab.objectguid NP_Root_A
object.rootref NP_RootRef

# H0/H1 — 중첩 인스턴스 생성 뒤 Entity 계층과 shadow store가 같은가.
scene.hierarchycheck

log.flush
quit
