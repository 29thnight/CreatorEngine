# 스킨 프록시 갱신 시나리오
#
# 본 팔레트는 프록시가 다시 만들어질 때만 렌더로 간다(ProxyCommand가
# m_FinalTransforms를 immutable buffer로 복사한다). X8이 프록시 발행을 dirty
# 게이팅으로 바꾸면서 마스크에 "팔레트가 바뀌었다" 축이 없었고, 그 결과 스킨
# 메시가 정상적으로 그려지되 첫 포즈에서 굳었다.
#
# 헤드리스는 프레임을 완성하지 않으므로 그림 대신 **프록시 커밋 누계**를 잰다 —
# 재생 중인데 커밋이 안 늘면 최신 팔레트가 렌더에 도달하지 않는다.
#
# 드롭 경로(LoadCachedModelShared)를 쓴다. model.load와 다른 로더이고,
# 사용자가 실제로 밟는 길이다.

scene.switch __SCENE__
wait 60
model.loadcached __MODEL__
wait 120
model.place __MODEL_NAME__
wait 60
play
wait 60
animator.status
wait 90
animator.status
wait 10
stop
wait 20
quit
